# Flip A Coin launch-preparation history

覆盖日期：2026-06-17 至 2026-07-11。

本文件压缩保存旧 `TASK_STATE.md` 在 2026-07-11 任务重置前的 live 状态；它仅用于历史追溯，不代表当前待办。

## Outcome

- 首发方向收敛为单桌 8 人、自动入座、弱社交、高频 Flip 的休闲成长游戏；旧多桌、自由移动、复杂观战和遗留系统不再属于主流程。
- 核心输入统一为 HUD、`Space` 和手柄 `RT`；单客户端已验证自动入座、Flip 结算、死亡回座和成长面板开关。
- 新档早期路径完成 Cash `$9`、Value 首级 `$12`、Rebirth `$250` 目标和 Coin Spread 首级价值曝光。
- 横屏设备模拟覆盖小屏 Android、iPhone 和 iPad；成长面板根布局及主要文字已通过模拟检查，真机触控仍需人工确认。
- Developer Product 与 Game Pass ID、发货和购买后刷新 happy path 已由用户人工验证；首发移除 Rewarded Ads。
- Flip 反馈已有 Heads/Tails、streak、Perfect、Edge Stand、Table Bonus、首次多币和观察者低噪音层级，真实 VFX/SFX 体感仍待最终验收。
- Coin Spread、多币中位 primary coin、Rebirth 永久树、装备购买/装备刷新和相关 analytics 源码链路已完成。
- Fake Player 不触发真实玩家共享奖励、稀有事件或真实玩家 analytics；座位等待、释放和重新分配源码闭环存在。
- 运行时合规文案已清理 `bet / wager / casino / payout / gambling / stake` 等包装。
- 收集、图鉴、套装、强社交、Timing Bonus 和其他新玩法被降为发布后候选，不再作为首发阻塞项。

## Remaining At Reset

- 真机触控目标、真手柄完整焦点导航和稳定双客户端/满桌验收未完成。
- 同桌广播可能遮挡核心 HUD 或成长面板；普通、高光和全桌结果的最终体感尚未人工确认。
- 首次 Rebirth 和首次多币的稳定运行态验收仍需补齐。
- 仓库已有 icon 和三张渲染式市场图，但仍缺真实运行 HUD、同桌高光及成长截图。
- `uiController` 在一次运行态检查中持有大量未挂载按钮对象，尚未证明是否随面板使用持续增长。
