# Flip A Coin Launch Media Guide

## Asset Order

1. `output/icon/flip-a-coin-icon-centered-512.png`：游戏 icon；小尺寸裁切时保持整枚硬币和下方光环完整。
2. `output/screenshots/flip-a-coin-market-abtest-a-core-1920x1080.png`：首张包装图，表达翻硬币主题；它是概念渲染，不应作为实际 UI 证明。
3. `output/screenshots/flip-a-coin-market-abtest-b-social-1920x1080.png`：第二张包装图，表达八人同桌和弱社交。
4. `output/screenshots/flip-a-coin-market-abtest-c-streak-1920x1080.png`：第三张包装图，表达多 Coin 和成长高光。
5. 真实运行首屏：必须清楚显示桌面、`FLIP`、Cash、Streak 和四项升级。
6. 真实同桌高光：Team Test 中捕获至少两名真实客户端、桌面反馈和不遮挡核心 HUD 的广播。
7. 真实成长时刻：捕获首次多 Coin 或 Rebirth 预览/完成状态，不能用受控假界面代替。

渲染式素材与真实运行素材必须同时存在。不要把概念图中的红色实体按钮描述成游戏内实际按钮；实际首发操作是黄色 HUD `FLIP`、`Space` 或手柄 `RT`。

## Short Video Shot List

总长建议 `12-18` 秒：

1. `0-2s`：进服后自动入座，镜头落到桌面和 `FLIP`。
2. `2-5s`：一次 Tails 和一次 Heads，展示两种结果都获得 Cash。
3. `5-8s`：购买 Value，HUD 清楚显示升级前后变化。
4. `8-12s`：streak 或 Perfect 高光，同桌广播保持在上中部且不遮按钮。
5. `12-16s`：首次多 Coin Flip；如果没有稳定多 Coin 会话，改用 Rebirth 预览，不拼接概念画面冒充实机。
6. `16-18s`：回到 `FLIP` 主循环，以游戏名和真实桌面收尾。

## Description Candidate

建议前两行：

> Take a seat and FLIP. Build Cash, chase streaks, and turn one coin into five.
> Upgrade each run, Rebirth for permanent table power, and share big moments with the whole table.

后续要点可写：

- Tap `FLIP`, press `Space`, or use controller `RT`.
- Heads and Tails both move your run forward.
- Unlock Coins, Desk Setups, Chairs, and multi-coin flips.
- No betting, wagering, or player-to-player gambling.
